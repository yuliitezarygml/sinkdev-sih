# Third-party brand icons

The bundled icons are used only to identify the corresponding service in the authenticator account list. All product names and trademarks belong to their respective owners.

- **Aegis Icons** — primary 2FA icon catalog, synced from `aegis-icons/aegis-icons` at commit `c249e94ed8581970cb3b806cc3170b672a011f2d`. The repository applies CC0 to its own work and documents the upstream licenses and trademark limitations in its README and license files.
- **Simple Icons** — Riot Games, Telegram, and Vercel vector paths, synced from `simple-icons/simple-icons` at commit `98820a4dc8c363ca72fa2c0d294ea4a0a9bba75d` (CC0-1.0). Its metadata points to the respective official brand sources.
- **Web3 Icons** — Bybit badge, synced from `0xa3k5/web3icons` at commit `763a55d66a03b21b603eb249f2df7c64a7522089` (MIT package metadata).
- **Cryptomus** — brandmark downloaded from the official Cryptomus brand-guideline package.
- **Majestic RP** — image from the official Majestic RP GitHub organization profile.

The catalog can be refreshed with `npm run icons:sync`.
